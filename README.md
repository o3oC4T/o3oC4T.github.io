# o3oC4T Portfolio Archive

GitHub Pages에서 별도 빌드 없이 동작하는 인터랙티브 포트폴리오입니다.

## 콘텐츠 수정

`data.js`에서 이름, 소개, 이메일, 경력, 프로젝트를 수정합니다. 프로젝트 이미지는 저장소의 `assets/` 폴더에 넣고 각 프로젝트의 `image` 값을 `assets/example.jpg`처럼 지정합니다.

## 로컬 미리보기

```bash
npx serve .
```

## 배포

`main` 브랜치에 push하면 GitHub Pages를 통해 배포됩니다.
